# ADR-001 — Shared card order, ack, and the room code

Status: accepted for the 4.2.6 shared-round package. This is not Fairway 5.0.

## Decision

Field order is one function on every phone: higher monotonic per-device `seq` wins; if `seq` ties, the greater `deviceId` in lexicographic order wins. `Date.now()` is not an order key. A stamp above `SEQ_MAX` (1_000_000), including a hostile value near `1e15`, is dropped.

A stroke stays in the queue until a GET of the HTTPS room **after** the PUT still shows that op as the winner. The PUT body, an MQTT payload, and a Drive file are not an ack. If the POST fails, the queue stays. Seal and leave detach only when the queue is empty and the status is synced.

MQTT may only wake an HTTPS GET. It does not apply JSON onto the card. A Drive file is not the shared room and must not be reported as synced.

A flush must not replace the live queue or the stamps taken after the network call with the snapshot from before the await. A stroke entered during the await stays on the card and is not synced until a later HTTPS GET shows it.

Join, boot, and sync do not re-stamp existing local fields. Only a real local edit allocates a new seq. Creating a room may mint one seq so strokes already on the card can be published.

Room codes and device ids come from `crypto.getRandomValues`. The alphabet stays `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`.

Joining a room clamps handicap to -10..54 before course handicap and stroke allocation.

`localStorage` stays the marker source of truth. IndexedDB stays a mirror. Backup schema stays 3. Product version stays 4.2.6.

## The code is only a bearer token

Anyone who knows the 6-character code can read and replace `https://mantledb.sh/v2/{code}/card`. A static PWA cannot authenticate the writer. This package does not add a backend, a write key, or a secret stored in the repo. This is not end-to-end encryption.

## Consequences

Honest phones can repair a hole that a hostile stamp used to lock, and a writer does not drop an acked stroke when the follow-up GET misses it or when POST fails. Two phones with equal or skewed clocks converge on the same seq/deviceId rule.

The room is still a public document. Possession of the code is the only access control.
